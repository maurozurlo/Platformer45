# Lienzo

Primer ítem del juego. Funciona como introducción y tutorial de mecánicas básicas: golpear objetos, separarse la cabeza, entrar en espacios pequeños, y combinar ítems en el inventario. Se consigue en el área inicial del juego, cerca del baldio donde vive Púbol.

- **Ramas**
    
    Se obtienen golpeando un árbol en la plaza. El árbol está claramente distinguido visualmente del resto. Introduce la mecánica de **interacción con objetos del entorno**.
    
    Se planea una animación para el momento en que caen las ramas, destacando la acción.
    
    El [vendedor de la tienda artística](Vendedor%20de%20Tienda%20Art%C3%ADstica%20211d96a049b6807bbc0ec6d3a27af588.md) sugiere que podrían usarse como parte de un lienzo improvisado.
    
    **NPC o señal cercana**
    
    Púbol o algún NPC podría estar cerca mirándolo. Incluso puede decir algo como:
    
    *"Ese árbol ya no da más, eh..."*
    
    **Un objeto ya caído cerca**
    
    Una rama en el piso que no se puede agarrar, pero sugiere que el árbol suelta cosas. Maki podria tener un boton para interactuar con la rama caida y decir algo absurdo como “Que asco, una rama en el piso, nunca agarraría algo así”
    
    ### . **Escena de la rama (Node2D o Area2D)**
    
    ```
    gdscript
    CopiarEditar
    # RamaSeñuelo.gd
    
    extends Area2D
    
    @onready var dialog_box = get_node("/root/DialogBox")  # Ajustá según dónde tengas tu sistema de diálogo
    
    func _ready():
        connect("body_entered", self, "_on_body_entered")
    
    func _on_body_entered(body):
        if body.name == "Player":
            dialog_box.show_text("Maki", "Qué asco. Una rama en el piso. Nunca agarraría algo así.")
    
    ```
    
    - El `Area2D` puede tener un `CollisionShape2D` pequeño y una `Sprite2D` para representar la rama.
    - Podés usar una señal como `interact_pressed()` si tenés un sistema de botón de acción en vez de detectar solo por proximidad.
    
    ---
    
    ## 🌳 Árbol interactuable (el verdadero objeto útil)
    
    ```
    gdscript
    CopiarEditar
    # ArbolGolpeable.gd
    
    extends Area2D
    
    var ramas_caidas = false
    
    @onready var inventory = get_node("/root/Inventory")  # Ajustá si tenés un sistema de inventario
    
    func _ready():
        connect("body_entered", self, "_on_body_entered")
    
    func _on_body_entered(body):
        if body.name == "Player":
            show_interact_prompt("Presioná [E] para sacudir el árbol")  # Opcional
            # Esperás a que el jugador presione el botón de acción
    
    func on_action_pressed():
        if !ramas_caidas:
            ramas_caidas = true
            inventory.add_item("Ramas")
            dialog_box.show_text("Maki", "¡Aja! Este árbol sí tira cosas útiles.")
        else:
            dialog_box.show_text("Maki", "Ya sacudí esto. No creo que tenga más ramas.")
    
    ```

## Puzzle combinado: Rama + Paloma

### 🧩 Situación

- Hay **una paloma** sentada en una rama alta del **árbol golpeable**.
- Al golpear el árbol:
    - **Cae la rama** → Maki la recoge.
    - **La paloma vuela** → se posa en otro lugar, dando inicio al **puzzle de la pluma**.
- **Sábana**
    
    Se encuentra dentro de una casa azul cercana. La casa tiene una ventana o entrada pequeña por donde Maki puede entrar usando solo la cabeza.
    
    Esto introduce la mecánica de **entrar con la cabeza a lugares inaccesibles con el cuerpo**.
    
    El entorno es simple (una cama y una silla), para no abrumar en esta etapa.
    
    El vendedor de la tienda artística también menciona la idea de fabricar un lienzo casero. Puede haber un globo flotante o un marcador INFO cerca de la casa para reforzar la pista.
    
    Maki puede decir en voz alta algo como: *"Che, creo que si me saco la cabeza puedo entrar por ahí..."*
    
- **Montaje del Lienzo**
    
    Una vez que se tienen la sábana y las ramas, se combinan desde el inventario para crear el **Lienzo**. No hay que ir a ningún lugar específico para hacerlo.
    
    Este evento da pie a que el vendedor reconozca el lienzo improvisado y permita avanzar con el primer encargo artístico. Sirve como puerta de entrada al resto del sistema de pintura del juego.
