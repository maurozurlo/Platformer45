# Cenizas (negro)

Ubicación: Volcán / cuartel de bomberos / playa
Mecánica: Puzzle
Componente de: Pinturas
Explicación: Los bomberos pueden decir que ayudan con problemas de fuego; diálogo cómico.
Notas: Si Maki se tira al volcán, su cabeza se prende fuego. Puede usarse para quemar árboles o pastos cercanos.
