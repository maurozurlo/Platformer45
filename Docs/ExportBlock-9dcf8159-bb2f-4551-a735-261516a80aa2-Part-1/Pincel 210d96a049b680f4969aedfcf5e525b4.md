# Pincel

### Segundo elemento del juego. Introduce puzzles más complejos, exploración en vertical y el uso de mecánicas como cavar y resolver acertijos. El objetivo es construir un pincel artesanal combinando dos elementos: una vara, una pluma.

- **Vara**
    
    Se encuentra en la montaña. Puede estar trabada entre piedras o colgando de un árbol seco. Para obtenerla, el jugador debe usar la mecánica de **cavar** o utilizar su cabeza para subir o empujar objetos. El lugar tiene un diseño más vertical, empezando a presentar desafíos de plataformas simples.
    
    Puede haber un **INFO pickup** o un personaje como **Púbol** que dé pistas sobre su localización.
    
- **Pluma**
    
    Se consigue en el **Santuario Sintoísta**, custodiada por una paloma. Está protegida por un puzzle de lógica que recuerda al del zorro, la cabra y el repollo. El jugador debe resolverlo para obtener la pluma. Este puzzle introduce al jugador en una lógica de “orden de acciones” y restricciones de movimiento, aumentando la complejidad.
